ClipDesk

ClipDesk is a small Windows program used by the operator of the YouTube channel Joachim Clips (@JoachimClipsTV). It runs on the operator's own computer. It follows public live streams the operator has documented rights to use, finds highlight moments, cuts short vertical clips and subtitles them locally, and uploads it to that same YouTube channel through the YouTube Data API. By default the operator approves each video first. The operator can instead let ClipDesk upload clips that pass an automatic quality check and have documented source rights, always as private videos. Scheduled public release is a separate, off-by-default option that needs an additional permission and the operator's explicit confirmation.

How ClipDesk uses a Google account

Only the operator connects a Google account, once, to authorize two YouTube permissions:

  • youtube.readonly: confirm that the connected account controls the Joachim Clips channel and show basic video counters.
  • youtube.upload: upload videos, private by default, to that channel.

If the operator ever enables scheduled public release, ClipDesk would additionally request youtube.force-ssl, only to change the visibility or publish time of videos it uploaded itself. This policy and the Google consent screen will list it before it is used.

ClipDesk is not a public service. It has no user accounts, no sign-up, no website back end and no servers.
