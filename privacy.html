ClipDesk privacy policy

Last updated: 19 November 2026. Operator: the operator of the YouTube channel Joachim Clips. Contact: GitHub issues. Back to the ClipDesk home page.

Google user data ClipDesk accesses

When the operator connects a Google account, ClipDesk requests two permissions: youtube.readonly (to confirm which YouTube channel is connected and read basic video information and counters) and youtube.upload (to upload videos the operator has approved to that channel and to set their visibility). Only the operator's own account is connected.

How data is used and stored

  • Google access credentials are stored only on the operator's Windows computer, encrypted with Windows DPAPI under the operator's Windows account.
  • A local queue stores clip metadata, upload history, YouTube video IDs and recent video counters on the same computer. Counters expire after seven days.
  • A video file and its title and description are sent to YouTube only when an upload is approved. ClipDesk communicates with Google and YouTube only to authorize, verify the channel, upload and read the status and counters of its own videos.
  • Subtitles are generated locally by a speech model on the computer. Audio and video are not sent to any other service.
  • ClipDesk reads public live streams of sources the operator has documented rights to use, and the live chat of Twitch channels it follows. Chat is used only to count message activity to detect highlights; message text and user identities are not retained. Video recordings and clips stay on the operator's computer until uploaded or deleted.
  • The local dashboard is reachable only from the same computer (127.0.0.1).

Sharing

ClipDesk does not sell, share, transfer or disclose Google user data to anyone, does not use it for advertising, and no person reads it other than the operator. ClipDesk has no server and no analytics or tracking.

Limited Use

ClipDesk's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. ClipDesk uses YouTube API Services and is bound by the YouTube Terms of Service. See also the Google Privacy Policy.

Deleting data and revoking access

The operator can delete stored credentials, counters and remote IDs with the program's disconnect command and can revoke ClipDesk's access at any time at myaccount.google.com/permissions.

Changes

If this policy changes, the date above is updated.
